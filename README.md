# -Cell-Phone-Case-Failure-Analysis
## Overview
This project explores operational data from three different machines manufacturing cell phone cases. The primary objective was to identify patterns related to machine performance and failure rates using clustering and visual analytics.

## Technologies Used
- Python (Pandas, NumPy)
- Data visualization: Matplotlib, Seaborn
- Machine learning: Scikit-learn (Clustering)
- Jupyter Notebook

## Objectives
- Combine datasets from multiple machines.
- Analyze and visualize batch performance.
- Apply clustering techniques to identify high-failure patterns.
- Interpret results and provide actionable insights.

## Key Findings
- Cluster 0 showed the lowest failure rate (~14%), suggesting more stable operating conditions.
- Clusters 1 and 2 had significantly higher failure rates (~46% and 40%), indicating areas for potential process improvement.
